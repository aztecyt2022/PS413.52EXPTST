# HENACY v1

**HENACY v1** is the default PS4 firmware **13.52** homebrew host.

**Website:** https://aztecyt2022.github.io/PS413.52EXPTST/

Native PS4 VSH test build, using Akari v1.2.2 by Jordy Nateur as the menu baseline: [download and setup](https://aztecyt2022.github.io/PS413.52EXPTST/vsh.html) · [source and restore instructions](native/vsh/README.md). PS4 13.52 hardware validation remains outstanding.
