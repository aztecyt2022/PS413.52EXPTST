HENACY v1 · VSH menu

A native PS4 home-screen panel based on the menu structure of Akari v1.2.2 by Jordy Nateur.

PS4 13.52 test build. Native compilation and host simulations pass. Physical PS4 testing is still required. Install both native modules before loading the test payload.

Download PS4 test kit · v0.1

What is included

  • Crimson, Ocean and Monochrome panel themes with adjustable opacity.
  • Console information, CPU temperature, SoC sensor and ShellUI update counter.
  • Statistics overlay, left/right placement and saved preferences.
  • DualShock controls, release handling, disconnect handling and a restore kit.

Install and open

  1. On your PC, download and fully extract the kit.
  2. Start your working HENACY on PS4 with its FTP server enabled.
  3. Run INSTALL.cmd on Windows and enter the PS4 IP address. The script backs up the existing ShellUI plugin and verifies both uploads.
  4. Reboot PS4, open the test host below and select Load exploit.
  5. On the PS4 home screen, press L3 + R3. Use D-pad, Cross and Circle. Release the chord after opening.

Open VSH test host

To restore, run RESTORE.cmd while HEN FTP is available, then reboot. Selecting the standard host alone may still reuse a plugin stored on the console.

The bundled README includes manual checks, recovery steps and log locations. Akari's PS3 binary and PS3-only controls are not included.
